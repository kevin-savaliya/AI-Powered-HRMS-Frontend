# AI-Powered HRMS - Frontend

A modern, responsive, and feature-rich Human Resource Management System (HRMS) built with React 19, TypeScript, and Tailwind CSS. This frontend integrates AI capabilities to streamline recruitment and employee support.

## 🚀 Key Features
- **Role-Based Dashboards**: Tailored interfaces for Admins, HR Managers, and Employees.
- **AI Chatbot**: An intelligent RAG (Retrieval-Augmented Generation) assistant that answers company policy queries using Google Gemini AI.
- **Recruitment Management**: Visual pipeline for tracking candidates, from application to onboarding.
- **Employee Portal**: Easy access to profile management, leave requests, and payroll information.
- **Analytics & Reporting**: Interactive charts and data visualization using Recharts.

## 🛠️ Tech Stack
- **Framework**: [React 19](https://react.dev/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS 4.0](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **AI Integration**: [Google Generative AI (Gemini)](https://ai.google.dev/)
- **Database/Backend Interface**: Supabase & Axios

## ⚙️ Installation & Setup
1. **Clone the repository**:
   ```bash
   git clone https://github.com/kevin-savaliya/AI-Powered-HRMS-Frontend.git
   cd AI-Powered-HRMS-Frontend
   ```
2. **Install dependencies**:
   ```bash
   npm install
   ```
3. **Configure Environment Variables**:
   Create a `.env` file and add your credentials (Supabase URL, API Keys, etc.).
4. **Run the development server**:
   ```bash
   npm run dev
   ```
